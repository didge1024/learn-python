# Curriculum & Free Courseware

A curated map of free, high-quality computer science courseware — with the standout
assignments worth actually doing. Everything here is legally free to use. Work through
them with Claude as your tutor: have it explain the concepts first, attempt the
assignment yourself, then ask Claude to review your solution.

> Etiquette: these are real university assignments. Try them honestly before asking
> for the answer — the struggle is where the learning happens. Use Claude to *unblock*
> and *review*, not to hand you finished code.

---

## 1. MIT 6.0001 / 6.100A — Introduction to CS and Programming in Python

The gold-standard intro. Beginner-friendly, but the problem sets are genuinely good.

- Course: https://ocw.mit.edu/courses/6-0001-introduction-to-computer-science-and-programming-in-python-fall-2016/
- Assignments: https://ocw.mit.edu/courses/6-0001-introduction-to-computer-science-and-programming-in-python-fall-2016/pages/assignments/
- Newer version (6.100L, Fall 2022): https://ocw.mit.edu/courses/6-100l-introduction-to-cs-and-programming-using-python-fall-2022/

**Best assignments (Fall 2016):**

| PS | Project | Skills |
|----|---------|--------|
| PS1 | **Paying off credit-card debt** — compute payments, then use *bisection search* to find the minimum monthly payment | loops, floats, search algorithms |
| PS2 | **Hangman** — full word-guessing game with hints | strings, conditionals, game state |
| PS3 | **Word Game (Scrabble-style)** — score words, play against a simple computer player | dictionaries, scoring, decomposition |
| PS4 | **Caesar cipher** — encrypt/decrypt text and crack a shifted message | string manipulation, brute force |
| PS5 | **RSS feed filter** — pull live news feeds and trigger on keywords | classes, real-world data, OOP |

## 2. MIT 6.0002 — Introduction to Computational Thinking and Data Science

The natural sequel. Optimization, simulation, and modeling.

- Course: https://ocw.mit.edu/courses/6-0002-introduction-to-computational-thinking-and-data-science-fall-2016/
- **Standouts:** knapsack / graph optimization, Monte Carlo simulations, modeling
  bacterial populations with drug resistance, curve fitting.

## 3. MIT 6.006 — Introduction to Algorithms

Once Python feels comfortable, this is the classic algorithms course.

- Course: https://ocw.mit.edu/courses/6-006-introduction-to-algorithms-spring-2020/
- **Standouts:** sorting, hashing, BFS/DFS, dynamic programming problem sets — all with
  autogradable Python components.

## 4. Harvard CS50P — Introduction to Programming with Python

Polished, modern, with an autograder (`check50`) and a capstone final project.

- Course: https://cs50.harvard.edu/python/
- Final project: https://cs50.harvard.edu/python/project/
- **Best assignments:** "Little Professor" (math game), "Working 9 to 5" (regex + time),
  "Figlet" (CLI tooling), and the open-ended **final project** — build anything.

## 5. UC Berkeley CS61A — Structure and Interpretation of Computer Programs

Deeper CS thinking in Python: recursion, higher-order functions, interpreters.

- Course: https://cs61a.org/
- **Legendary projects:** **Hog** (dice game + strategy), **Cats** (typing test),
  **Ants** (tower-defense game), and **Scheme** (write an interpreter in Python).

## 6. Where this repo goes next: systems & deployment

Python is the on-ramp. To learn to *build and run* software on modern systems:

- **Docker — official "Get Started":** https://docs.docker.com/get-started/ — containerize
  one of the projects above.
- **Kubernetes Basics (interactive):** https://kubernetes.io/docs/tutorials/kubernetes-basics/
  — deploy your container to a cluster.
- **KodeKloud / Play with Kubernetes** (free labs): https://labs.play-with-k8s.com/
- **The Missing Semester of Your CS Education (MIT):** https://missing.csail.mit.edu/
  — shell, git, tooling, the stuff courses skip.

---

## Suggested order

1. **6.0001 / CS50P** — learn the language (do PS1–PS5)
2. **6.0002** — computational thinking
3. **CS61A** — deeper programming ideas (Hog → Scheme)
4. **6.006** — algorithms
5. **Docker → Kubernetes** — containerize and deploy a project you built
6. **Missing Semester** — sharpen the surrounding tooling, anytime
