# learn-python

A personal repo for learning Python — notes, exercises, and small projects.

## Structure

- `exercises/` — bite-sized practice problems
- `projects/` — small end-to-end scripts and apps

## Getting started

```bash
python3 --version   # 3.10+ recommended
python3 exercises/hello.py
```
