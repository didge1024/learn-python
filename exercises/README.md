# Warm-up Exercises

Tiny, friendly programs to get comfortable **before** tackling the big MIT problem sets.
Do them in order — each one takes a few minutes.

Run any of them like this:

```bash
python3 exercises/01_variables.py
```

Each file has two parts:

1. **Examples that already run** — read them, run them, see the output.
2. A **`# YOUR TURN`** challenge — a small thing for *you* to write. When you finish one,
   run the file again to see your code work.

| # | File | You'll learn |
|---|------|--------------|
| 0 | `hello.py` | running your first program |
| 1 | `01_variables.py` | variables, text, numbers, f-strings |
| 2 | `02_conditionals.py` | `if` / `elif` / `else` decisions |
| 3 | `03_loops.py` | repeating things with `for` and `while` |
| 4 | `04_lists.py` | storing lots of things in a list |

**Stuck on a challenge?** Open Claude in this folder (`claude`) and ask:
*"I'm working on `exercises/03_loops.py` — can you give me a hint without the answer?"*

When these feel easy, run the [placement diagnostic](../assessment/README.md) and move
into the [curriculum](../curriculum/README.md).
